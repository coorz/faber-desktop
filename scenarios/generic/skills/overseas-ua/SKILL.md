# 海外买量平台规格（2026 版，改动频繁，产出前以官方文档校对）

## Meta (Facebook/Instagram/Audience Network)
- Feed 1:1 1080x1080；Stories/Reels 9:16 1080x1920（顶部/底部 250px 安全区）
- 主文案 125 字符内（折叠线），标题 40 字符内；视频 ≤ 241 秒，前 3 秒决定完播
- 素材多样性强奖励：同 campaign 提供 3:4 竖版优先，多比例混投

## Google App Campaigns（AC）
- 不做手动定向，系统自动组合素材：文案 5 组标题(30字符)+5 组描述(90字符)
- 图片：横 1200x628、竖 1080x1920、方 1200x1200；视频 ≥10s（YouTube 侧自动生成可选）
- 视频是 AC 效果核心：15-30s，演示核心玩法/功能在前 5 秒

## TikTok Ads
- 9:16 1080x1920，5-60s；原生 UGC 风格完爆精致广告片
- 前 3 秒 hook + 字幕常驻（默认静音自动播放）
- Spark Ads（加热达人原生帖）效果通常高于 In-Feed

## Apple Search Ads（ASA）
- 无独立广告素材，直接使用商店页：截图/视频/文案即素材
- Custom Product Page（CPP）按关键词定制商店页；ASA Today 帖子用 1920x1080

## Unity Ads / AppLovin / IronSource（休闲游戏主力）
- Playable ads：HTML5 单文件 ≤ 5MB（部分平台 ≤ 2MB），15-60s 试玩，直出 ZIP
- Rewarded video 15-30s；插屏静态 320x480 / 480x320 / 1024x768
- 结尾 end card 必须有明确 CTA + 商店跳转

## 通用规范
- 所有素材文案先英文本地化，再铺 DE/FR/JA/KO/PT-BR（按买量重点市场）
- 商店截图 iOS 用 6.9"（1290x2796）+ 6.5"（1242x2688）两档可覆盖全部设备要求
- Google Play：功能图 1024x500 PNG/JPG，手机截图 16:9 或 9:16，每边 320-3840px
- 归因与买量埋点：AppsFlyer/Adjust 链接进 end card 与社交渠道
