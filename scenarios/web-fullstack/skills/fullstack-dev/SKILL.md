# 全栈开发

- 先定接口契约（路由表 + 请求/响应示例）再写实现；前后端共用类型定义。
- 数据库变更用迁移文件（幂等、可回滚），禁止手改生产库；启动时自动跑未执行的迁移。
- 环境变量集中在一个 config 模块读取，缺关键变量启动即报错，不要运行时才炸。
- 前端页面完成后用 curl 冒烟核心接口，再跑一次构建，两个都过才算任务完成。
- 静态资源与 API 同源部署时，注意 SPA 路由 fallback 到 index.html。
